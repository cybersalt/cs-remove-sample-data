🚀 Version 1.0.0 May 28, 2026

First public release.

📦 What it does

A Joomla 5/6 administrator component that detects and removes the items installed by Joomla's core sample-data plugins (Blog and Multilingual), with preview, per-item opt-out, type/title/status filters, and a full activity log.

📦 Features

  • Blog sample-data removal. Detects every item the core plg_sampledata_blog plugin creates: ~11 articles, 4 categories, 4 tags, 3 menu types, ~17 menu items, ~12 modules, 1 custom field + group, 1 editorial workflow with 9 stages and 12 transitions.
  • Multilingual sample-data removal. Detects the per-language menus, language switcher module, per-language language-menu modules, per-language sample categories and articles, and optionally disables plg_system_languagefilter.
  • Locale-aware detection. Aliases are reconstructed from translated titles via ApplicationHelper::stringURLSafe() using the same language file the sample-data plugin used, so detection works on non-English sites.
  • Blog-on-multilingual detection. When Joomla's blog plugin is invoked on a site that has content languages installed, it appends -{lang} to every alias and ({LANG}) to every title. The Blog detector reads #__languages and computes both -{lang} and _{lang} alias variants plus title variants so these get caught as well.
  • Tight multilingual scope. The Multilingual detector gates the entire detection on whether at least one mainmenu-{lang} menutype is present, so blog-on-multilingual items don't false-positive as multilingual sample data.
  • Edited-item safeguard. Items whose title no longer matches the sample-data title, or that were edited more than 120 seconds after creation, are flagged with an "Edited" badge so you can review them before deciding.
  • Items list view with per-column dropdown filters, sortable columns, pagination, and stats cards that link into pre-filtered views.
  • Scan view as a single flat table with one filter dropdown per column, master checkbox in the column header, shift-click range selection, and "all ticked by default."
  • Confirmation modal with a backup-acknowledgement checkbox and lock-out overlay during the run.
  • Activity log + log viewer with the standard Cybersalt rig — Refresh / Download CSV / Clear-all-with-modal, hotlinked stats cards, text filter, color-coded levels, expandable detail.

🔐 Security baseline

Passes the Cybersalt security review with zero HIGH and zero MEDIUM findings. Every controller method enforces permission, every state-changing endpoint validates CSRF, every SQL query uses quoteName() + bound parameters or strict int casts, every template echo is escaped, CSV log download is sanitised against formula-injection, the token-refresh endpoint sets no-store + nosniff headers, and exception messages are HTML-escaped before reaching flash-message renderers.

🏛 Architecture

  • Joomla 6-native MVC component (works on J5+ too).
  • PHP 8.1+, modern Toolbar API, DatabaseInterface DI, Joomla\Input\Input, no deprecated APIs.
  • Token-refresh AJAX endpoint baked into the component (Joomla 6 doesn't ship the legacy plg_system_token that earlier Joomla versions used for this).
  • Scan view inlines its JS and CSS directly into the page HTML to sidestep proxy/CDN cache issues with /media/ assets.

🎨 UX

  • Single "Tick all" button at top, shift-click range selection within visible rows, per-column filter dropdowns.
  • One flat table layout — cleaner for the "tick what you want gone" mental model than per-section cards.
  • Dark-mode safe — no bg-light/bg-white, no btn-outline-*. Edited-row highlight is a 4 px warning-yellow left border that themes correctly.
  • Standard Joomla-style master checkbox with indeterminate state.
  • Clickable row titles open the underlying record in the matching core Joomla editor.

⚙️ Settings

  • Log retention period.
  • Republish the main menu module after multilingual removal (opt-in).
