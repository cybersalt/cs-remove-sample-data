# cs-remove-sample-data

A Joomla 5/6 administrator component that detects and removes the items installed by Joomla's core sample-data plugins (Blog and Multilingual), with a preview, per-item opt-out, and a full activity log.

## What it removes

**Blog sample data** (`plg_sampledata_blog`)
- 11 sample articles + their custom-field values and frontpage-feature flags
- 4 sample categories
- 4 sample tags
- 3 sample menu types + ~17 sample menu items
- 12 sample modules (admin + frontend)
- 1 sample custom field + 1 field group
- 1 sample editorial workflow + 9 stages + 12 transitions

**Multilingual sample data** (`plg_sampledata_multilang`)
- Per-language menu types (`mainmenu-{lang}`) and their menu items (home + all-categories)
- Language Switcher module + per-language language-menu modules
- Per-language sample categories and articles + their association rows
- Optionally: disables `plg_system_languagefilter` (surfaced as a toggle in the UI)
- Optionally: republishes the main menu module that the sample data unpublished

## How detection works

Aliases generated by the sample-data plugins are not hardcoded — they're produced at runtime from translated titles via `ApplicationHelper::stringURLSafe()`. This extension reuses the same algorithm and language strings to reconstruct the exact aliases the plugin would have produced, then looks them up by alias in the appropriate context. That means detection works on non-English sites too.

Items whose title doesn't match the original sample-data title (or whose body has been edited) are flagged as **Edited** and left unchecked by default so you can review them before deciding.

## Safety

- Preview every item before any deletion.
- Per-item opt-out via the Keep checkbox.
- "Edited" items left unchecked by default.
- "Type REMOVE to confirm" gate before any deletion.
- Lock-out modal during the run prevents double-submit and tab navigation.
- Every action (and side-effect like disabling a plugin) is logged to the activity log.

**Take a full site backup before running.** Removal cannot be undone from inside this extension.

## Requirements

- Joomla 5.0+ or 6.0+
- PHP 8.1+

## Installation

Download `com_removesampledata_v1.0.0_*.zip` from the releases page and install through Extensions → Install.
